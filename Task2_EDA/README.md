# Exploratory Data Analysis (EDA) Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) using Python.  
The analysis helps understand the dataset structure, identify trends, detect missing values, and visualize relationships between variables.

---

## Objectives
- Understand the dataset structure
- Identify missing values and duplicates
- Perform statistical analysis
- Visualize data using charts and graphs
- Detect patterns, trends, and outliers

---

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## Dataset
The dataset contains sample student performance data including:
- Name
- Age
- Gender
- Study Hours
- Marks

---

## Features of the Project
- Data Loading
- Data Cleaning
- Missing Value Detection
- Duplicate Removal
- Statistical Summary
- Histograms
- Scatter Plots
- Correlation Heatmap
- Boxplots
- Pairplots
