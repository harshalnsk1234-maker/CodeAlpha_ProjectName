# Tasks Included

## Task 1 - Web Scraping

### Description
This project performs web scraping using Octoparse to extract data from websites and save it in structured format for analysis.

### Tools Used
- Octoparse
- CSV/Excel

### Features
- Extracted website data automatically
- Exported scraped data into CSV/Excel format
- Organized and cleaned collected data

### Files Included
- output.csv
- screenshots
- README.md

# How to Run the Projects

## Install Required Libraries

```bash
pip install pandas numpy matplotlib seaborn beautifulsoup4 requests
```

---

## Run Web Scraping Project

## How to Run the Web Scraping Task

1. Open the Octoparse application.
2. Load the web scraping task/project.
3. Run the scraping workflow to collect website data.
4. Export the scraped data into CSV or Excel format.
5. Save the exported file in the project folder.

### Output
The scraped data is stored in:
- output.csv
- output.xlsx

---

## Run EDA Project

```bash
python eda_project.py
```
